# SwiftCart E-commerce Platform Case Study

## Organisation / System Overview

SwiftCart is a simulated e-commerce platform that allows customers to browse products, place orders, make payments, and track deliveries.

The platform is designed to support the management of customers, products, inventory, orders, payments, and delivery information.

## Users of the Database

The main users of the database are:

- Customers
- System administrators
- Warehouse staff
- Delivery personnel

## Major Data to be Stored

The database will store information relating to:

- Customers
- Products
- Product categories
- Orders
- Order items
- Payments
- Inventory
- Deliveries

## Key Database Operations

The database will support the following operations:

- Register customers
- Add and update products
- View available products
- Place customer orders
- Record order items
- Process payments
- Update stock quantities
- Track delivery status
- Retrieve customer order history
- Generate sales and inventory reports

## Purpose of the Database

The purpose of the SwiftCart database is to provide a structured and reliable system for managing e-commerce transactions and supporting the day-to-day operations of the platform.
