# Advanced Database Portfolio

**Course:** MIT 8103 – Advanced Database Systems  
**Case Study:** SwiftCart E-commerce Platform

## Overview

This repository contains my Advanced Database Systems practical portfolio for MIT 8103. The portfolio uses **SwiftCart**, a simulated e-commerce platform, as the case study across all five activities.

SwiftCart manages customer information, products, categories, orders, payments, inventory and delivery records. The portfolio demonstrates relational database design, SQL query optimisation, transaction management, NoSQL modelling, and distributed/cloud database concepts.

## Portfolio Structure

### Portfolio 1 – Database Design and Modelling
Folder: `portfolio-1-database-design`

This section contains:
- SwiftCart case study description
- Entity and attribute definitions
- ER diagram
- Relational schema
- Normalisation to Third Normal Form (3NF)
- MySQL database schema
- Sample data

### Portfolio 2 – Query Processing and Optimisation
Folder: `portfolio-2-query-optimisation`

This section contains:
- SQL retrieval and JOIN queries
- Query execution plans
- Index creation and optimisation evidence
- Before-and-after `EXPLAIN` results
- Performance analysis

### Portfolio 3 – Transactions and Concurrency
Folder: `portfolio-3-transactions-concurrency`

This section demonstrates:
- `COMMIT`
- `ROLLBACK`
- Transaction processing
- Concurrent database sessions
- Row-level locking
- Lock wait timeout evidence

### Portfolio 4 – NoSQL and Advanced Data Models
Folder: `portfolio-4-nosql`

This section uses MongoDB to demonstrate:
- Document-based data modelling
- Nested objects and arrays
- SwiftCart order documents
- Queries by customer, payment status and product
- Comparison between relational and NoSQL approaches

### Portfolio 5 – Distributed and Cloud Database Exercise
Folder: `portfolio-5-distributed-cloud`

This section uses MongoDB Atlas to demonstrate:
- Cloud database deployment
- Distributed database concepts
- Replication
- Availability
- Consistency
- Sharding and scalability considerations

## Technologies Used
